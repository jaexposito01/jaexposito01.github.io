# OpenClaw Personal

OpenClaw Personal es una instalación de un asistente de inteligencia
artificial para uso personal de José Antonio Expósito Carrillo.

Permite consultar información de las cuentas de Google autorizadas
por su titular, incluyendo correo de Gmail, calendarios y archivos
de Google Drive, para responder preguntas y organizar información.

El acceso configurado actualmente es de solo lectura. Cada cuenta
requiere autorización expresa mediante Google OAuth.

El asistente se ejecuta en un equipo del titular y utiliza un modelo
de OpenAI mediante una conexión con su cuenta de ChatGPT. Según la
consulta realizada, la información recuperada puede enviarse a OpenAI
para generar la respuesta.

Esta web contiene información sobre el asistente; no permite acceder
a las cuentas conectadas ni iniciar sesión en OpenClaw.
